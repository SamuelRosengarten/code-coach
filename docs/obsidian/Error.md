# Diagnostics

Code Coach is built around [[Error Handling]]: catching a student's mistake and turning it into a lesson instead of a dead end, right inside the [[VS Code Extension]].

## Display

[[Error Display]] shows the problem in-editor as it happens — unknown languages are grouped under "Others" on the graph for a cleaner view, and error names and descriptions are kept clear and student-friendly.

## Storage and history

[[Error Storage]] and [[Error History]] keep a record of what a student has run into before. [[Auto-clear Data]] automatically cleans up old [[Error History]] so that record doesn't grow forever.

## Hints

[[Error Hints]] turn a raw error message into something a student can learn from.
